# Установка: от GitHub до первого соединения

[English](INSTALL.md)

## Перед установкой

1. Нужен Home Assistant версии 2026.10.0 или новее с рабочей интеграцией Bluetooth и адаптером, поддерживающим подключения.
2. Подтвердите модель: A1 Ultra, product `hc7n0urm`, категория `jtmspro`. Одного названия продавца недостаточно.
3. Замок должен быть привязан к вашему SmartLife и работать в приложении. Сбрасывать его для установки не нужно.
4. Сначала получите четыре значения ниже. Репозиторий не содержит готовых данных какого-либо замка.

## Откуда взять данные замка

Компонент не входит в Tuya и не импортирует секреты из другой интеграции HA. Один раз получите данные **своего устройства**:

| Поле формы HA | Источник |
| --- | --- |
| Device ID | Список устройств привязанного облачного проекта Tuya; в ответе API — поле `id`. |
| UUID | Ответ с информацией об устройстве, поле `uuid`. Это НЕ UUID сервиса Bluetooth. |
| Local key | Тот же ответ, поле `local_key`. Это НЕ секрет API-проекта. |
| BLE unlock check | Запись состояния с `code: ble_unlock_check`; скопируйте целиком Base64 из `value`, без кавычек. |

1. Войдите на [Tuya Developer Platform](https://iot.tuya.com/). В **Cloud → Development** создайте или откройте проект типа Smart Home с дата-центром, соответствующим вашему аккаунту SmartLife.
2. В проекте откройте **Devices → Link Tuya App Account**, привяжите аккаунт QR-кодом через сканер SmartLife. Убедитесь, что ваш замок появился в списке устройств.
3. Откройте **API Explorer** проекта. Запросите сведения по Device ID. [Документированный запрос информации](https://developer.tuya.com/en/docs/cloud/d00d20c097?id=Kag2xtiyewd3r): `GET /v1.0/iot-03/devices/{device_id}`; в ответе предусмотрены UUID и local key. Названия разделов и доступные сервисы отличаются: аналогичная операция может называться **Query Device Details** или **Query Device Details in Bulk**. Нужны реальные, не замаскированные значения именно вашего устройства.
4. Запросите состояние: `GET /v1.0/devices/{device_id}/status`. Найдите `ble_unlock_check`. Если ответ со сведениями уже содержит `status`, значение может быть там. Описание схемы `Raw` — не само значение.
5. Альтернатива **только для BLE unlock check**: диагностика уже установленной Tuya-интеграции в HA иногда содержит это поле. Откройте Настройки → Устройства и службы → Tuya → ваш замок → Скачать диагностику. Наличие данных и маскирование зависят от интеграции; UUID и local key там могут отсутствовать или быть скрыты. Диагностический файл не публикуйте.
6. Если Tuya сообщает об истёкшей подписке, отсутствии прав или скрывает нужные значения, остановитесь на этом шаге и восстановите доступ в своём проекте Tuya. Компонент не обходит ограничения аккаунта и не извлекает ключи из Bluetooth-рекламы. Бесплатный тариф и автоматическая настройка для любого пользователя не гарантируются.

Пароль SmartLife и Access Secret проекта в компонент вводить не нужно. IP-адрес замка для BLE тоже не нужен.

## Установка через HACS

1. Откройте HACS в Home Assistant. В меню выберите **Пользовательские репозитории / Custom repositories**.
2. Вставьте `https://github.com/asemenov566/tuya_smartlock_local_ble`, тип **Интеграция / Integration**, нажмите Добавить.
3. Найдите **Tuya Smartlock Local BLE**, откройте карточку и нажмите **Скачать / Download**. Если релизов ещё нет, HACS берёт ветку по умолчанию.
4. Перезапустите Home Assistant. Откройте **новую вкладку с главным адресом вашего HA**, дождитесь загрузки главной страницы и перейдите в Настройки → Устройства и службы.
5. Если обнаружено устройство FD50 — нажмите Добавить/Настроить. Иначе выберите **Добавить интеграцию → Tuya Smartlock Local BLE**. Если список пуст, разбудите замок и повторите.

## Добавление замка и первая связь

1. Отключите BLE-соединение SmartLife с замком; проще временно выключить Bluetooth телефона. Другие BLE-интеграции этого же замка должны быть отключены.
2. Выберите устройство по имени и Bluetooth-адресу. Сам факт обнаружения FD50 ещё не подтверждает модель.
3. Если появится выбор модели, выберите **A1 Ultra**. Вставьте UUID, local key, device ID и BLE unlock check в поля формы.
4. Отправьте форму. Компонент проверит BLE-сессию и запросит состояние. **Мотор при этой проверке не запускается**, калибровка не выполняется. При неверных данных или недоступном замке форма покажет ошибку.
5. После успеха откройте страницу устройства: появятся управление замком, батарея и настройки. Постоянное соединение включено по умолчанию. Настройки могут оставаться неизвестными до получения отчёта или успешной записи — начальные значения не выдумываются.
6. В безопасном положении замка вручную проверьте закрытие и открытие, убедитесь в физическом движении при выключенном Bluetooth телефона. Направление и калибровку проверяйте осознанно: калибровка меняет настройку хода механизма.

Ключи сохраняются локально в записи интеграции HA, которой управляет сам HA (`.storage`). Редактировать файлы не требуется. Резервные копии HA тоже могут содержать ключи — храните их закрыто.

## Вариант без HACS: ZIP

На GitHub нажмите **Code → Download ZIP**, распакуйте архив на компьютере. Скопируйте только каталог `custom_components/tuya_smartlock_local_ble` в `custom_components` каталога конфигурации HA. Итоговый файл должен находиться по адресу `/config/custom_components/tuya_smartlock_local_ble/manifest.json`, без дополнительной папки репозитория. Перезапустите HA и выполните те же шаги добавления выше. Git на сервере не нужен. Обновлять ручную установку тоже нужно вручную.

## Ошибки, удаление и откат

- **Интеграции нет в списке:** проверьте путь каталога, перезапустите HA, обновите браузер и посмотрите журнал HA.
- **Замок не найден:** проверьте Bluetooth HA, питание и расстояние; разбудите замок, отключите телефон и другие BLE-клиенты. HACS сам Bluetooth не сканирует.
- **Ошибка соединения:** проверьте все четыре значения и выбранный замок. После сброса/перепривязки старые ключи могут перестать работать. Повторите рядом с адаптером.
- **Статус не совпадает с механизмом:** это предполагаемое состояние по командам и отчётам, а не датчик закрытой двери; проверьте физическое движение.
- **Удаление:** удалите запись именно этого замка в интеграции HA, затем удалите пакет через HACS и перезапустите HA.
- **Откат:** перед обновлением сохраните установленный код и настройки. Верните предыдущую версию и её настройки, затем перезапустите HA. Не редактируйте `.storage` при работающем HA.

## Совместная установка с Tuya Local BLE

Domain и каталог этого компонента — `tuya_smartlock_local_ble`. Компоненты с другим domain можно установить рядом. Но конкретный физический замок должен быть настроен только в одной активной BLE-интеграции: иначе клиенты могут конкурировать за соединение. При изменении общих зависимостей любого из пакетов совместимость следует перепроверить.

HAOS предусмотрена как вариант установки: зависимости работают внутри Home Assistant, а не устанавливаются в базовую ОС. Нужны актуальная HAOS, HA 2026.10.0+ и поддерживаемый Bluetooth-адаптер. Аппаратная проверка этой версии именно на HAOS пока не проведена.
